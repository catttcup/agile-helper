# Agile Helper (Ржомба)

Веб-сервис для Agile-команд с интеллектуальным помощником.

## Стек технологий
- React
- Vite
- Tailwind CSS
- dnd-kit (drag and drop)

## Реализованный функционал (на текущий момент)
- Канбан-доска с перетаскиванием карточек
- Создание задач с полным набором полей
- Детальная карточка задачи (Slide-over)
- Встроенный ИИ-ассистент (интерфейс)
- Фильтрация задач по исполнителю, приоритету и меткам
- Добавление комментариев
